# Knowledge Map 0.0.13 — UI/UX 打磨

首次正式发布（非 pre-release）。功能与布局数据格式沿用 0.0.11/0.0.12（schema3），本轮只改界面结构与样式。

## 界面变化（0.0.12 → 0.0.13）

- **「重新构建」进入顶部工具条**：与「重置视角」并列，随时可点，不必关开视图；按钮固定为 `↻` 图标（悬停提示含义），构建中图标旋转、按钮禁用并提示「正在重新构建图谱」，构建结束自动恢复。
- **构建完成提示 2 秒后自动消失**：改成画布底部居中的胶囊提示（「构建完成 · N 篇笔记 · M 个节点 · E 条边 · X 秒」），不再常驻占行；构建中/取消/失败提示仍然保留，需要时可在状态条里取消。
- **「调整布局」入口收进顶部工具条**：新增 `✥` 图标按钮；进入编辑后顶栏下方出现一条全宽工具条（选父级/撤销/重做/恢复此组/全库恢复自动布局 + 状态提示），退出后整条隐藏。阅读时右上角不再有浮动面板，图谱有效显示区是完整矩形。
- **工具栏与面板不再互相遮挡**：布局工具条展开时，图例、搜索命中列表与画布可见区按工具条真实高度避让；对象详情侧栏打开时工具条自动让出侧栏宽度。
- **顶栏不再被文字挤爆**：两个动作按钮固定为单字形图标（悬停提示与读屏标签提供含义），宽/窄窗口都保持一行，不再把「重置视角」挤出右缘。
- **细节**：状态胶囊与图例的分层、「调整布局」激活态高亮、编辑提示文案、按钮图标对齐。

## 缺陷修复（候选验收期间）

- **删除任一标题后，同一笔记的标题层级不再整篇重排**（2026-11-04 日常库验收 Node 11 反馈）：当一篇笔记里存在「同名且正文为空」的知识点时，删除笔记中任意一处标题会让该笔记顶层分组的旧布局被保守校验拒绝，导致所有一级标题按自动布局重新打包（实测 H1 最大偏移约 64 世界像素，放大后肉眼明显）。现在空正文的同名标题仍按保守规则比对——同名计数改变或证据不一致时照旧回退——但在纯增删且证据一致时保留已保存布局，只让真正变化的子树重排。新增合成回归：`scripts/layout_incremental_check.mjs` 覆盖「空正文同名标题 + 无关删除后仍保留修复」与「删除同名标题本身仍回退」。
- **布局编辑提示指向实际按钮**：提示原文写「点『结束调整』退出」，但收到顶栏后按钮只显示 `✥` 图标。改为「再次点击顶栏 ✥ 退出」，`aria-label` 仍随状态在「调整布局 / 结束布局调整」之间切换。

两处修复后的候选构建：`main.js` 332,824 B sha256 `e568296bf37fdd2adcd636027cf3fdd4618d43cdd189e64cc512d60b50632111`（0.0.13 首次正式发布将使用该构建）。

## 未改动的契约

- 布局数据：schema3（笔记级共享 structures）、`data.json` 格式与迁移逻辑不变，0.0.12 升级无需迁移。
- 交互契约：capture / reconcile / apply、拖动/保存/撤销/Esc、预览与悬停行为不变。
- 渲染与物理：`upstream/` 的渲染与布局物理逻辑未改，只新增 HUD 结构与样式。
- 内部 id 仍为 `knowledge-graph-smoke`（0.0.12 起显示名为 Knowledge Map）。

## 已知限制

- 不要对渲染页整页 reload（会让插件视图停在初始化态；FB-006 已定因为测试脚本行为，非插件缺陷）。重载视图请在 Obsidian 内关闭再打开标签页。
- 单组/局部修复预算：受影响节点超过 5000 或子节点超过 128 时拒绝自动修复并回退；撤销栈 50 步且仅当前会话。
- 仅桌面（`isDesktopOnly: true`），最低 Obsidian 1.6.7。
- 0.0.10 及更早版本读到 schema3 会禁用布局调整并保留数据；回退前先备份 `data.json`。
- 悬停摘要取自内存索引，不写入布局数据。

## 安装与升级

见 `docs/INSTALL.md`（发布资产：`main.js`、`manifest.json`、`styles.css`、`SHA256SUMS`；只替换这三个文件即可升级，`data.json` 保留）。校验 `SHA256SUMS` 后再安装；首次使用前建议备份插件目录。
