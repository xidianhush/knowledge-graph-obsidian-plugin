### 内容顺序与时长

- 0–2 秒：品牌图标与总览引导。中文「把知识 / 变成地图」，英文 “YOUR KNOWLEDGE. / ONE MAP.”。
- 2–4 秒：平移探索。
- 4–7 秒：缩放层级。
- 7–10 秒：预览笔记/标题。
- 10–13 秒：知识链接。
- 13–17 秒：自定义布局。
- 17–20 秒：名称、平台范围与社区搜索安装。

顺序依据 README 的 Pan → Zoom → Preview → Follow the connections → Arrange what matters → Install；双语共用镜头，分别写自然短标题。素材均为原有合成库桌面演示，不伪造操作界面或新增功能。

### 视觉与声音建议的具体实现

- 沿用原品牌图形；深色背景与品牌紫，稀疏坐标/圆环作为辅助图形。
- 中文用等线粗体，英文用 Bahnschrift，区分标题、紫色关键词和辅助字幕，避免整屏同样大小文字。
- 由品牌圆环衔接地图的圆形揭示，产品画面轻滑入，短淡化衔接；镜头交替留出文字区域，布局片段使用更大画面。
- 加入原创程序合成的轻电子底音与切点短音，没有采样外部音乐或人声，没有配音。音频峰值/RMS 记录于 timeline-v2.json；这不等于用户已认可音乐风格或混音。
- 科技感优先服务真实画面和信息层级；若增加故障/扫描等更强效果，应由用户看过当前方向后再决定，避免遮挡操作。

交付：`.local/promo-015/knowledge-map-20s-{zh,en}-v2.mp4`、对应 SRT、`timeline-v2.json`、`storyboard-{zh,en}-v2.jpg`、`build_promo_v2.py` 和原创底音 WAV。v1 保留，未覆盖。

本轮技术核验：两版均为 20.000 秒、1920×1080、24 fps、H.264 视频 + 48kHz 双声道 AAC；ffmpeg 完整音视频解码无错误，已查看中英七镜联系表，没有发现字幕越界或截图拉伸。用户已认可 v2 科技感与节奏；音频细节没有单独评价，不推定为逐项混音验收。本轮未改变插件运行文件、未运行插件测试、未发布视频。
