# Knowledge Map 统一同步候选：PC / iPad 联合测试

这是 0.0.16 的独立验证候选，显示版本仍为 0.0.15。不要替换日常库或旧测试库里的插件。使用本包新库；正常设置入口不再需要测试命令或场景标记。

本次建议坚果云新空远端：**{{REMOTE}}**。两端使用同一个远端，不复用旧远端。共享目录为库内 Knowledge Map Sync/attempts-v1/。设置、视角、界面状态留本机；“已写共享目录”不代表已到达另一端。

## 打开与连接准备

1. 分别解压 PC / iPad 包，在 Obsidian 中打开包内 **Knowledge Map Unified PC** / **Knowledge Map Unified iPad** 文件夹为库；不要将解压的上一级目录当库。首次打开只在这两个合成测试库中信任并启用 **Knowledge Map Sync Candidate**。
2. 两端从左侧插件图标或命令「从当前库构建知识图谱」建图，保持一个图谱标签。PC 的 A.Second 预置为旧布局，iPad 为自动布局，笔记内容相同。
3. 打开「设置 → Knowledge Map Sync Candidate」，向下找到「图谱布局同步」。状态初始为未启用。点「导出同步状态」会在库根目录生成唯一的 Knowledge-Map-Sync-Report-*.json；可按下文名称重命名。报告含合成布局/操作和状态，不含设备密钥或同步服务凭据。
4. 在这两个新库分别安装/配置自己的 Nutstore Sync，连接上述新空远端。关闭服务的自动同步，本轮按步骤手动同步；**插件的普通布局保存仍会自动写入共享目录**。需要传输 Synthetic/ 与 Knowledge Map Sync/ 的文件；.obsidian 配置和状态报告无需传输。不要将 PC 的整个 .obsidian 覆盖给 iPad。软件仍会核对外部配置变化，这个配置建议不替代程序防护。不要将密码、令牌或整个配置文件发回。

## 一：首次加入与取消

1. 两端各导出 **起点-PC / 起点-iPad**。
2. PC 点「新建共享布局」，确认选择；再点「审阅并加入」，点「导入本机已有布局」后先取消。完全退出并重开 PC Obsidian，重新建图并打开设置，原布局应保留、未加入。再次审阅并确认导入，导出 **导入-PC**。
3. PC 手动坚果云同步至完成；iPad 手动同步至完成，建图，设置里点「查找共享布局」，下拉选择 PC 的那份（核对当前逻辑库 ID），点「选择共享布局」并确认。
4. iPad「审阅并加入」选择「采用共享布局」并确认，导出 **采用-iPad**。它应采用 PC 布局，不发布空布局或新导入。

## 二：普通保存自动排队与反向接收

1. PC 回到图谱，点 ✥「调整布局」，移动 A.Second 后结束。**不用找手动发布命令**；状态应先为本机已保存/等待写入，再成为已写共享目录（过程可能很快）。
2. PC 手动坚果云同步 → iPad 手动同步。保持图谱可见等待自动接收；必要时点设置里的「检查共享布局」。iPad 应显示 PC 修改。
3. iPad 再移动同一个 A.Second，结束编辑，按 iPad 同步 → PC 同步的顺序传输。PC 应显示 iPad 修改。两端导出 **双向后-PC / 双向后-iPad**。两端显示尺寸/视角可以不同，局部布局应一致。

## 三：关闭期间工作、冷开与明确恢复

1. PC 在设置里「关闭同步，保留本地工作」，回图谱再移动 A.Second。此时本机可以保存，共享历史不增加。
2. 完全退出并重开 PC，建图，确认本地修改仍在，导出 **关闭重开-PC**。
3. PC 点「启用同步」，打开「审阅待发布布局」后先取消。导出 **恢复取消-PC**；取消不能发布。再审阅并确认，导出 **恢复确认-PC**。
4. PC 同步 → iPad 同步，两端检查，确认恢复的布局一致。

## 四：不同修改的冲突审阅与最终重开

1. 两端先各手动同步到相同布局，然后暂停坚果云传输（已关闭自动同步，此时不要点手动同步）。
2. PC 和 iPad 分别把 A.Second 移到明显不同的位置并结束编辑。各自本机可自动写共享目录，但尚未互相收到。
3. 按 PC 同步 → iPad 同步 → PC 同步传输，再各点「检查共享布局」。若有服务尚未传完，先等完成再检查。两端导出 **冲突-PC / 冲突-iPad**；此时不要再次拖动，原分支应保留。
4. 只在 iPad 点「审阅布局冲突」，选一份布局后先取消，确认图谱未被取消动作改变；再审阅、选择期望布局并确认。iPad 同步 → PC 同步 → 两端检查，两端应采用所选布局。
5. 完全退出并重开两端 Obsidian，各建图、检查、导出 **最终重开-PC / 最终重开-iPad**，各截一张最终图谱和一张设置状态。

## 一次性回交

将上述 JSON 报告（共 13 份）、最终两端图谱与设置截图集中发回，并反馈：预览能否辨认、取消是否不改变布局、状态说明是否清楚、普通保存是否无需手动发布。移动端体验由你判断，Windows 原生预检不能替代它。

若状态显示容量、校验失败、身份恢复或等待文件/笔记，请先导出当时报告和截图，记下具体操作后暂停这一步；不要删除共享历史、重置身份、覆盖 .obsidian 或用其他库的报告替代。
