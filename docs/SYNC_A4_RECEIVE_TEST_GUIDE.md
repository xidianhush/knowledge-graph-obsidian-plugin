# SYNC-A4 原生接收测试

解压后，把 `Knowledge Map A4 Receive` 打开为独立 Obsidian 库，启用同名测试插件。PC 和 iPad 可各自使用一份刚解压的库。此轮用合成文件模拟到达，无需登录坚果云。

1. 在命令面板运行「从当前库构建知识图谱」，保持图谱打开。等图谱显示后稍等一两秒，让首次扫描结束。可以选中一个节点或缩放画布，方便观察位置和视角。
2. 运行「A4 · 投放布局样本 1」。等待提示「A4 · 布局已应用（1/2 条操作）」。观察当前图谱更新，视角与选中项保留。这个阶段先观察自动接收。
3. 运行「A4 · 投放布局样本 2（笔记先不添加）」。应提示布局正在等待兼容的图谱，此时保留上一步布局。再运行「A4 · 添加迟到笔记」，等待图谱重建并提示「A4 · 布局已应用（2/2 条操作）」。
4. 两端各运行一次「A4 · 导出本机测试报告」。报告位于库根目录，文件名以 `SYNC-A4-native-` 开头。完全退出 Obsidian 后重开测试库，再次打开图谱并导出一份报告。每端把两份报告发回即可。

如果自动接收没有更新，先导出一份报告，再运行「A4 · 检查已到达的布局文件」。注明在哪一步用了手动检查。如果手动检查后仍卡住，请保留报告并附上当时的提示。测试期间请用选中或缩放观察视角，布局拖动会保存为本机草稿并暂停接收，留待另一轮验证。
