# G7 独立合成库：实际0.0.15回退与返回候选

仅使用本轮全新PC/iPad库；原G6/G5及日常库保持。本包为0.0.15独立候选，使用正式插件ID`knowledge-graph-smoke`以核验原位替换，不能放进日常库。PC/iPad分别在各自新库执行，本轮无需坚果云传输，也不要求两端产生相同逻辑ID。新远端`{{REMOTE}}`仅作为以后另验传输的独立路径预留。

库外`G7-正式0.0.15`保存已核对发布摘要的原版三文件，`G7-返回候选`保存本轮候选三文件。三文件是main.js、manifest.json、styles.css；data.json另按以下明确选择处理。完整备份和兼容输出含本地配置及未知字段，请私有保管。

## 1. 建立新库状态

解压PC或iPad新库，打开后先“从当前库构建知识图谱”。进入本库Knowledge Map G7 Candidate的“图谱布局同步”，点“新建共享布局”，审阅确认；再点“审阅并加入”，明确选择“导入本地已有布局”并确认。两库均预置可导入的合成布局，没有安装身份或既有接受历史。

正常拖动一个标题、结束调整，确认已保存；记录当前逻辑ID。关闭图谱布局同步，再拖动另一个标题结束调整，使本地形成不同的未发布草稿。保留两种布局截图及同步报告。先做PC，PC步骤顺利后再做iPad；不重复G6容量/旧离线端实验。

## 2. 明确兼容导出

保持布局同步关闭，点“导出恢复备份”，等待完整核验。备份原目录和名称不动，另复制整目录到库外。

在“导出给0.0.15的布局”选择“导出已接受布局”或“导出已保存但未发布的草稿”。点“审阅导出0.0.15兼容文件”，核对预览、来源和目标路径；先取消一次，原布局/连接/草稿应保持，再审阅确认。两种选择可各导出一份。界面显示“兼容文件已完整核验”后，整份`data.json`+`manifest.json`目录另复制到库外；同步报告不能替代它。

来源选择在设置页：找到紧邻“审阅导出0.0.15兼容文件”按钮、当前显示“导出已接受布局”的下拉框，点框本身或右侧箭头展开，选择草稿。弹出的布局预览只展示已选来源，不在弹窗内再次选择；若已打开默认已接受布局预览，先点“取消”返回设置页再改下拉框。

当前候选只在本次设置页面内记住已核验的恢复备份：离开后重新进入设置页，或修改备份目录，会清空这条临时记录，兼容审阅按钮因此变灰；已有备份文件仍须保留。遇到此情况，在当前页再导出一份完整恢复备份，等“恢复备份已完整核验：路径”出现后，不离开设置页即选择来源并完成兼容审阅。可先在同一设置页完成两种导出，再将完整恢复包与兼容目录一起复制库外；正式替换运行文件前须完成库外保全。如果已有核验路径而按钮仍灰，回交当页截图及报告检查图谱就绪，不启用同步或发布草稿来绕过。

兼容目录与完整恢复包是两份不同材料。完整恢复包保全已接受/草稿/未完成工作，兼容data.json只包含本次明确所选布局及当前有效本地设置。若有pending、冲突、未知输入或未保存提示，先保留完整恢复包和报告回交，不能将这些状态静默压成单一布局。

若输出失败或输入变化，不按成功路径回退；保留部分输出和报告重新备份/审阅。正文与完成清单均须通过完整性校验；底层存储在写清单后出错可能留下清单，不代表界面已确认成功，也不能只凭文件存在认定完整。

## 3. 只在新测试库切换实际正式版

完全退出Obsidian。先复制测试库插件整个目录至库外，再把`G7-正式0.0.15`三文件复制到测试库`.obsidian/plugins/knowledge-graph-smoke/`，把上一步所选兼容data.json复制为该目录的data.json。只替换这四个已明确文件，不删除App存储、同步历史或备份。

重开并构建图谱，确认显示的是所选已接受布局或草稿，本地设置/UI保持。正式版没有布局同步设置。再拖动一个不同标题、结束调整，完全退出重开，确认旧版新编辑保持；完全退出后把此时data.json另复制到库外，保留为“旧版期间新工作”。

## 4. 返回候选

保持Obsidian退出，把`G7-返回候选`三文件复制回同一插件目录，保留刚才旧版写出的data.json、原App存储及完整恢复包。重开候选，先构建图谱；原新逻辑ID、原接受历史与候选未发布草稿应保持，布局同步应仍关闭。

旧版期间data.json里的新布局不会自动发布/覆盖原逻辑库；它仍在旧版文件和库外副本。恢复到旧版编辑结果是另一项明确选择，不能误点“恢复待发布布局”把原候选草稿当旧版新工作。若需要将旧版新布局导入共享，先保全两边，回交报告后按独立新逻辑库/明确恢复路线处理。

回交候选回升后的同步报告、正式版编辑后重开及回升后图谱截图、选择的导出来源、实际耗时和操作感受。iPad替换插件文件的方法沿用此前实际可用工具，只操作本轮新库；遇阻保留现场回交。旧版本/候选混写同一共享历史不在支持范围。

本轮尚不授权升级日常库、清理私有存储或发布0.0.16；实际iPad/服务结果由用户确认，技术预检不代签体验。

数据说明：共享目录的布局操作包含相对笔记路径、标题/结构证据和坐标，由你配置的文件同步工具传输。设置、视角及界面状态留在本机；设备私有日志/身份位于App本地存储，不是旧版能读取的data.json。恢复备份/兼容文件含当前本地配置和未知字段，可能包含私人信息，应私有保管。备份不导出设备密钥或可移植接受账本；共享哈希不是加密或写入者身份认证。正式0.0.15本身没有新布局同步能力，旧/新版本不能同时写同一逻辑同步历史。
