# SYNC-A3 长日志重开测试

请把 ZIP 解压到独立目录，在 Obsidian 中将 `Knowledge Map A3 Replay` 作为仓库打开，并启用 `Knowledge Map A3 Replay Probe`。压缩包包含隐藏目录 `.obsidian`。测试使用本机 IndexedDB，无需登录坚果云。

1. 打开命令面板，运行「打开 SYNC-A3 长日志测试」，点击「高复用 · 3,967 条事件」。首次会生成约 64 MiB 合成数据。保持 Obsidian 在前台，等到显示「首次测量完成」和报告文件名。准备数据耗时单独记录。
2. 同一次启动中点击「低复用 · 2,000 条事件」，再等到显示「首次测量完成」。两种样本各占约 64 MiB 合成正文。如果设备空间有限，可以先只做高复用样本。
3. 完全退出 Obsidian。PC 结束当前 Obsidian 应用实例，iPad 在 App 切换器划掉 Obsidian。重新打开这个测试库，再运行同一条命令，依次点选刚才准备过的样本。此时应显示「完全重开测量完成」。同一次启动内再次点击时，面板会标为「本次启动内复测完成」。
4. 测试库根目录会生成 `SYNC-A3-replay-…json`。请保留每种样本的首次与重开报告。PC 可提供测试库路径，iPad 可发回报告文件。若显示「测量暂停」，同样保留该次 JSON。

高复用样本的日志多次引用同一份 blob。低复用样本的每次状态变更各引用一份 blob。两种样本均有 4,095 条 IndexedDB 记录和 67,108,352 字节合成正文。报告包含打开总耗时、逐条事件及 blob 读取、验签、进度锚核对和容量清点。日志回放用时包含内部步骤，各项时间不能再相加。数据准备和报告导出均单独处理。
