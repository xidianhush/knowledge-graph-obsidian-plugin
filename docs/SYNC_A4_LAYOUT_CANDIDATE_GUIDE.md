# SYNC-A4 独立图谱候选

只在配对的合成库中使用。这个候选从 Knowledge Map 的图谱编辑生成布局操作。退出「调整布局」会保存本机草稿，命令面板的「A4 候选 · 发布或重试本机布局草稿」才写共享文件。发布提示只确认本机已核验文件并接受布局。坚果云仍需手动同步。

## 准备

分别打开配对包中的 `Knowledge Map A4 Layout PC` 和 `Knowledge Map A4 Layout iPad`，保留隐藏的 `.obsidian`，信任库并启用 **Knowledge Map A4 Layout Candidate**。仅在这两个测试库安装并登录 Nutstore Sync。两端使用同一个新建空远端 `{{REMOTE}}`，与日常库及此前测试目录互不包含。选择双向同步并关闭自动同步，排除 `.obsidian`，允许同步 `Synthetic/` 和 `Knowledge Map Sync/` 下的文件。

两端打开图谱，在未编辑时先同步合成笔记并确认两端都能看见 `A` 与 `B` 的标题。

## 顺序实传

1. PC 调整 `A` 的标题 `Second`，退出布局编辑，再运行发布命令。手动按 PC → iPad 同步。iPad 等图谱显示调整后的布局。
2. iPad 调整 `B` 的标题 `Fourth`，退出布局编辑，再运行发布命令。手动按 iPad → PC 同步。PC 应保留第一轮布局并应用第二轮调整。
3. 完全退出并重开两端的独立库。打开图谱，核对两处调整都保留。分别用命令面板的「A4 · 导出本机测试报告」导出 JSON。报告文件名以 `SYNC-A4-native-` 开头，导出后暂停同步并直接分享文件。附上看到的图谱结果。

## 异常

出现等待、冲突、同步报错或内容差异时，暂停下一轮，保留两端共享文件并导出报告。若坚果云生成额外文件，附实际相对路径和文件本身。候选的传输目录为 `Knowledge Map Sync/attempts-v1/`。独立路径仍有精确路径被抢占后覆盖的风险，正式 v2 发布门禁关闭。

本指南覆盖顺序真机实传。并发编辑、同路径竞争和容量边界需在另一个干净目录按后续方案测试。
