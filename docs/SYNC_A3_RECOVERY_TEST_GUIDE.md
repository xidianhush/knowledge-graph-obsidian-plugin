# SYNC-A3 备份恢复测试

解压 ZIP，在 Obsidian 中将 `Knowledge Map A3 Recovery` 打开为独立库。启用同名插件。恢复流程使用本机存储，无需登录坚果云。

1. 在命令面板运行「恢复图谱布局备份」，点「建立本机恢复工作区」。备份路径已填入库内的旧版布局样本。
2. 点「预览备份」，应显示「预览就绪 · 1 个布局组」。点「确认保存草稿」，应显示「设置和布局草稿已保存」。草稿供后续处理，当前图谱继续使用已保存的布局。
3. 退出 Obsidian，重新打开同一测试库并再次运行恢复命令。应显示「已读回恢复草稿 · 1 个布局组」。
4. 点「检查缺失提示（模拟）」。应显示「待恢复。找不到进度锚对应的私有日志，请保留现有资料。」这项检查只在读取时模拟找不到文件，随后点「重开恢复工作区」应读回原草稿。
5. 点「导出本机验证记录」，保留库根目录下的 `SYNC-A3-recovery-…json`。PC 可提供测试库路径，iPad 可发回 JSON。

候选也支持库内兼容包目录。该目录名须为导出时的包 ID，内含 `manifest.json` 和 `data.json`。
