# A5 显式解决 Same 布局冲突

本轮用独立小样本图谱验证“审阅 → 取消 → 重开仍暂停 → 明确选择 → 两端收敛”。仅针对不同操作 ID 的同组并发修改。原操作文件保留，新生成一条解决记录；同 ID 不同正文、未知文件、摘要损坏和精确路径覆盖继续按原门禁暂停，不在此窗口内强行解决。正式 v2 发布门禁保持关闭。

## 准备和制造冲突

1. PC/iPad 分别解压新包并打开 `Knowledge Map A6 Resolve PC` / `Knowledge Map A6 Resolve iPad`，保留库名与隐藏的 `.obsidian`。在 PC 使用短路径，例如 `D:\R5\`。启用 Knowledge Map 候选。
2. 两端安装 Nutstore Sync，选择新的空远端 **{{REMOTE}}**，双向同步，关闭实时/启动/定时同步，配置目录 `.obsidian` 不同步。排除报告 `SYNC-A4-native-*.json` 与 `SYNC-A6-startup-*.json`，允许 `Knowledge Map Sync/`。本轮只有几份操作文件，无需重做千文件测试。
3. PC 同步一次，再 iPad 同步一次，等待完成。两端运行「从当前库构建知识图谱」，等图谱显示。确认操作目录此时没有旧操作。
4. 两端实际断网。PC 在「调整布局」中将 A.Second 向左拖，iPad 将 A.Second 向右拖；各自退出布局编辑，再运行 **「A4 候选 · 发布或重试本机布局草稿」**。两端应各看到自己的方向。
5. 恢复联网，按 **iPad 同步 → PC 同步 → iPad 再同步**，每次等完成。两端各运行「A4 · 检查已到达的布局文件」。应保留两笔操作，各端仍显示自己的方向，冲突暂停。
6. 两端各运行「A4 · 导出本机测试报告」，保留为“冲突-PC / 冲突-iPad”。

## PC 取消选择，再重开

1. 暂不再同步。在 PC 运行 **「A5 候选 · 审阅并解决同组布局冲突」**，窗口应展示两份布局预览，分别对应向左/向右。
2. 点击任意预览，确认按钮才可用。此次点击 **「取消选择」**，不要确认。图谱仍显示 PC 向左的布局，原始两份操作保留，不增加解决文件。
3. 完全退出 PC Obsidian，再重开本测试库。运行「A4 · 检查已到达的布局文件」（会先确保图谱就绪），然后导出报告，保留为“取消重开-PC”。应仍为两份操作、自己的旧布局与冲突暂停。iPad 此阶段不必重复退出。

## PC 确认，再传到另一端

1. PC 再运行 A5 审阅命令，点击标为 **「本机已保存」** 的预览，核对 A.Second 向左，再点 **「确认并保存决定」**。
2. 等待本机完成提示，再运行 A4 检查并导出报告，保留为“决定已保存-PC”。预期新增第三份操作文件，前两份保持原样；本机无待发布草稿，解决记录已接受。这里的提示仅说明本机完成，不代表 iPad 已收到。
3. 按 **PC 同步 → iPad 同步 → PC 再同步**，逐次等完成。两端各运行 A4 检查，预期都显示选择的向左布局。
4. 两端各截图并导出报告，保留为“解决后-PC / 解决后-iPad”。
5. 完全退出两端 Obsidian，再重开各自测试库，各运行 A4 检查并导出报告，保留为“解决重开-PC / 解决重开-iPad”。预期仍一致，无未解决冲突。

## 异常和回传

若提示“共享输入或图谱已变化”，先保留现场并导出报告。若没有已确认的待发布决定，可重新审阅；不得删除原始操作或强行覆盖。若窗口显示“此前已确认的布局”，说明决定已持久保存，可重试同一决定，关闭窗口会保留它；不代表撤销。出现未知输入或确认后又有新操作时，导出报告发回，候选可能继续暂停，避免复用过期决定。不要在两端同时确认解决方案。

正常共 **8 份报告**：冲突双端 2、取消重开 PC 1、决定已保存 PC 1、解决后双端 2、解决重开双端 2。原文件名可保留，报告里有步骤运行记录；回传时注明对应阶段即可。另附两端解决后截图，并反馈预览能否辨认、取消/确认提示是否清楚。PC 可提供库路径，iPad 分享 JSON。

本轮只用新独立库；之前测试库与证据保留。正式候选支持范围、旧快照导入及其余门禁另行处理。
