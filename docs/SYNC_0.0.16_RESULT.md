- [Nutstore Sync 官方 README](https://github.com/nutstore/obsidian-nutstore-sync)：支持双向/单向/镜像，存在路径过滤、大小限制及单独配置目录选项；这些能力说明不代表用户实际配置。网页与 raw manifest 的缓存版本不同，故不以其替代用户两端实际版本。

- [Obsidian 官方 API](https://github.com/obsidianmd/obsidian-api/blob/master/obsidian.d.ts)：文件接口能力参考，不替代 iPad/最低宿主实测。
