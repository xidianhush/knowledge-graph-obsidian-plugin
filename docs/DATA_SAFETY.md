# 数据、隐私与恢复边界

## 读取与写入

- 建图先按include/exclude筛选，再读取选中Markdown；指定API Key路径被额外排除。插件不编辑笔记正文。
- 未加入时，本机配置与布局使用插件data.json；加入后还依赖App本地身份和IndexedDB私有日志。复制data.json不能复制可信的接受事实。
- Knowledge Map Sync包含相对路径、标题/结构和坐标。第三方工具可将其上传到其服务；哈希校验不是加密或作者认证，目录写入者属于信任范围。
- 备份、兼容导出和诊断报告可能包含布局/路径、配置与未知字段。不得直接公开原始包或日志。状态报告不能代替完整恢复备份。

## 完整性与恢复

共享记录检查规范正文、摘要、库ID、因果、结构和预算。损坏/未知/缺失记录可使操作暂停；随机独立文件名降低合作写者碰撞，不保证任意外部写者下原子不覆盖，也不能发现首次观察前已消失的所有记录。

备份目录拒绝绝对路径、点段、配置目录与同步根；清单使用固定名称、长度与摘要逐项核验。私有状态丢失、磁盘失败和超限仍可能阻止保存；未知字节不能凭摘要重建。

关闭同步保留工作，不等于卸载或删除App存储。卸载、清理App数据或丢失唯一设备副本可能使工作无法恢复。操作前导出完整包，原位保留并另复制库外；恢复会再次核验，不以旧成功提示替代当前完整性。

## 本轮核验范围

新增自动检查验证恢复目标/文件名与库ID的非法路径在写入前被拒绝；发布检查验证缺失/空文件、私有产物、版本映射和复用输出目录污染。源码/运行资产加入常见密钥形状和用户主目录路径防漏检查；这是有限模式防漏，不是完整秘密扫描。

HTML审阅：正式建图管线生成excerpt而非HTML preview；Obsidian路径使用原生MarkdownRenderer。HUD仍有旧浏览器payload的HTML preview fallback。该入口不应承载不可信的外部HTML；本轮没有证明其对任意HTML安全，也没有为了无依据的漏洞结论改变现有渲染行为。新增外部payload导入前必须另行规定和验证安全呈现。

Windows/iPad原生、实际传输、升级/回退与新用户体验仍按最终候选另验。已有保护和历史通过不能作为全场景安全保证。

## 公开前

审阅确切的拟提交差异及最终三运行文件，不整包dist/.local，不提交真实笔记/截图/快照/配置。报告问题只提交合成复现与脱敏原因；发现疑似敏感数据时停止公开原件，先确认安全的报告方式。
