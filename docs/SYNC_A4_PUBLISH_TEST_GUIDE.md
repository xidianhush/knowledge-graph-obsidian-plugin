# SYNC-A4 安全发布接口检查

PC 和 iPad 分别解压同一份 ZIP，将 `Knowledge Map A4 Publish` 打开为新的独立 Obsidian 库。只在这个库启用同名探针。本轮使用本机合成文件，无需配置坚果云。

1. 打开命令面板，运行「A4 · 运行发布接口检查」。保持 Obsidian 在前台，等到「A4 报告已保存」提示。报告位于库根目录，文件名包含 `-first-`。
2. 完全退出 Obsidian。PC 用应用的退出命令，iPad 在应用切换器里划掉 Obsidian。重新打开同一个测试库，运行「A4 · 检查退出重开后的发布状态」。第二份报告的文件名包含 `-reopen-`。
3. 每端发回这两份 `SYNC-A4-publish-…json`。如果出现「A4 检查暂停」，发回提示文本和已经生成的报告即可。

探针会比较 `Vault.create`、`Vault.rename` 和 `DataAdapter.rename` 对同名目标的行为，并用合成 JSON 观察并发期间能读到的内容。第二轮复核退出前预留的两种发布边界，以及故意留下的一份不完整文件。重开检查只读取样本文件，碰撞和未触发索引延迟等结果保留在报告里。正式发布仍需验证写入期间的真实中断与跨工具不覆盖。
