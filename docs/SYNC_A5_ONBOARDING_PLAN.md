## 设计与范围

目标：schema3 已有手动布局首次加入同步时，先预览和明确选择，保留原插件数据，取消不发布、重试/重开不重复。覆盖一端有布局另一端为空、两端各有不同旧布局。schema1/2 保留已有核心迁移检查，本批原生候选不扩展其支持声明。

复用 `createDurableSyncSession.join()`、attempts-v1、私有配置投影和 A5 解决流程。给现有持久核心增加只读加入预览，并将确认绑定到本机布局、图谱 epoch 与完整共享目录指纹。导入仍为无前驱根操作；采用共享不发布。未知/损坏/缺前驱/同 ID 异正文保持暂停。已发布中断不允许取消已落盘事实，提供明确继续入口与稳定 ID。

选择：复用现有宿主并以新的 OnboardEmpty/OnboardBoth 标记启用。另写导入协议会分裂备份与恢复语义；先空初始化再补按钮会提前建立虚假接受事实，因此不采用。实现方式由 Codex 决定；产品体验仍待用户验收。

未加入时 store 读原布局并锁定布局编辑；不初始化投影/协调器、不启动接收。图谱就绪后显式打开审阅，选择导入本机或采用共享。成功建立接受事实后初始化私有配置投影/协调器、应用接受快照，再启动普通接收。当前非布局设置从最新源读取，不用备份覆盖。
