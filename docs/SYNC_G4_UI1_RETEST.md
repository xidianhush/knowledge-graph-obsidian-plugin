# G4-UI1 设置页横条复验

2026-11-16。使用原Knowledge Map G4 PC/iPad测试库，保留已验收的25操作、无Fifth现场。无需更换远端、重新加入或重做同步测试。版本仍0.0.15独立候选，本包包含已验收FB2连接锁修复及本轮设置页样式修复。

## 更新

完全退出两端Obsidian。解压更新包，将 `knowledge-map-sync-unified` 中的 `main.js`、`manifest.json`、`styles.css` 替换到各自原G4测试库的 `.obsidian/plugins/knowledge-map-sync-unified/`。

只替换这三个运行文件，保留data.json、本机存储、笔记、连接与共享历史。iPad沿用此前成功访问隐藏目录的方法。关闭其他未更新的同步候选窗口；旧候选仍可能占用连接兼容锁。不要覆盖日常库。

## 两端各检查一次

1. 重开原G4库，进入插件设置，滚到靠下的「应用设置」与「图谱布局同步」。**没有状态提示文字时，应没有横条覆盖设置项**。上下滚动，开关和输入框文字应完整。
2. 点「检查范围」：应出现正常检查结果文字。有文字的提示仍会在滚动时保持可见，这是原来的设计。
3. 点「撤销未保存修改」清空提示，再滚到相同位置：应不残留空白横条。不必改设置、保存、同步、审阅或重新加入。
4. 各导出一份同步状态：**UI1-设置后-PC.json / UI1-设置后-iPad.json**；各截一张无提示文字时的设置页，反馈空条是否消失、检查结果是否可见、清空后是否恢复正常。

如仍有横条，请停在当时页面，回交截图并说明是否含提示文字；无需重新安装或清理身份。本轮技术验证覆盖Windows原生及浏览器触屏视口，iPad真实显示仍需这次复验确认。
