# U4：正常设置页与状态/冲突入口

更新：2026-11-14（Asia/Shanghai）。按用户要求完成 [统一候选计划](SYNC_UNIFIED_CANDIDATE_PLAN.md) 的 U4 实现和隔离技术验证。正常设置接线仅进入独立统一候选；实际 Obsidian 原生预检、PC/iPad 包与用户体验验收留 U5，不放行默认产品或正式发布。

## 用户入口

新增 `src/sync/obsidian-sync-settings.mjs` 和 `src/i18n.sync.js`。统一候选在原有插件设置页的 display 中追加「图谱布局同步」一节，保留原设置功能。无需场景 marker 或临时测试命令，提供：

- 新建/发现/选择共享布局、当前逻辑库及旧 v2 只读提示、启用/关闭、审阅并加入、检查共享布局。
- 复用已有左右布局的首次加入和冲突预览；选择后仍需明确确认。取消保留原件，不接受、不发布。
- 审阅待发布布局：展示旧 pending 和最新已保存草稿；取消留本机。确认只授权审阅时的那份状态，有新保存、接受或图谱代次变化时旧确认失效。
- 外部设置待审：比较当前/外部设置，明确保留、采用或无冲突合并。取消继续使用当前设置，不将外部布局变成接受；本地设置在审阅后变化也需重新审阅。
- 未完成连接选择的重新审阅：保留同一选择/ID，禁止另建连接或启停绕过；确认目录当前状态后继续，不重建旧身份/日志。

处理中禁用操作按钮，审阅窗口打开时禁止重复操作。离开设置页会关闭窗口并撤销 token；异步预览在页面关闭后才返回，也不再弹窗。所有内容以 textContent/实际 SVG 渲染，不将标题、路径或错误当 HTML。

## 状态与宿主约束

中英文区分本机已保存、等待发布、已写共享目录、等待前驱/笔记、冲突、校验失败、容量暂停、最新修改未保存、关闭保留本地工作、身份恢复及外部设置待审。共享写入成功来自真实发布结果；接收成功不会显示为本机发布，旧成功也不能盖住新操作的暂停/错误。文案不承诺云端或所有设备已经完成传输。

宿主新增只读 `discover()` 和有界 `subscribe()`，页面加载/查找本身不创建身份；状态观察者不能控制事务，异常隔离。原始会话仍不向 UI 暴露可任意调用的写接口。`previewPublication/confirmPublication`、`previewConflict/confirmConflict`、`previewExternalSettings/confirmExternalSettings` 使用一次性、会话/图谱代次/可靠内容绑定的审阅 token；冲突决定仍走原 session 的完整扫描/暂存/发布、store 保留和 quota 门禁，不放宽协议。

连接选择在持久意图或设备连接后遇到目录变化时，registry 的 pending 必须先完成明确重审。U4 将其暴露为状态和按钮；在提交可信选择前，不打开未绑定连接的私有 session/backend，关闭重开也保持这条约束。原 ID、密钥、锚和旧账本不删除。

候选构建显式收集新 UI、预览与双语字典。加入说明仅在统一候选中使用新的自动排队文案；旧独立候选的手动流程说明保留，不通过重复字典 key 静默覆盖。默认 i18n 门禁包含新字典，401 个 key / 41 个模板绑定检查通过。

## 本轮验证与证据

- `node scripts/sync_settings_check.mjs`：**17 项**状态检查，含旧发布成功后的新暂停/错误、外部设置待审、未完成连接选择和未加入时无图谱提示。
- `node scripts/sync_settings_host_check.mjs`：**5 项**实际组件组合检查。覆盖观察/取消不写、恢复草稿过期确认、保留双分支的冲突决定、外部设置过期确认，以及连接意图/设备连接两个中断位置的冷开重审。使用真实 registry、签名 session、quota/coordinator/lifecycle/U2，注入 App/锁/内存后端契约。
- `npm run test:sync-settings-browser`：**10 组**隔离 Chrome 真 DOM 按钮与真实 IndexedDB。实际点击新建/选择/加入/取消/启停/恢复/冲突/外部设置/中断选择恢复；两个模拟 App 域共享合成布局文件，冲突决定后双方接受 5 笔历史、原件摘要保持。host 关闭重开读回同一 IndexedDB 接受，不重复导入/发布。此冷开是同一浏览器进程内的宿主重开，不能冒称原生 App 冷启动或进程退出。
- 桌面 1360×960 与 **1024×768** 的中英文设置页/审阅窗口均自动检查无横向溢出，保存 8 张截图；已目视抽查设置页和预览的文字、按钮、边界。视口尺寸检查不是 iPad 或触摸体验验收。
- 最终 `npm test`：构建 + **29 个合成脚本**，退出码 0；包含既有图谱渲染/布局交互契约、U1–U3 与新状态/宿主检查。原统一宿主磁盘 `test:sync-unified-disk` **8 次真实进程退出**本轮复跑通过，关闭/半写/发布恢复与签名身份保留。

最终命令、退出码、原始日志、浏览器目录、截图及源/默认构建/独立候选摘要：`.local/sync-016/unified/u4/regression-summary.json`。浏览器检查使用项目既有 Python Playwright + 本机 Chrome，独立无界面实例；App、Modal、共享文件及设备锁域为契约适配，私有存储为真实 Chromium IndexedDB。没有使用用户浏览器或日常库，不计为 Obsidian/Nutstore/iPad/OS quota/断电通过。

独立只读审阅指出 **1 个 Important**（选择中断后普通 UI 无法重审）和 **1 个 Minor**（页面关闭后异步预览仍弹窗）；均用失败用例复现、修复，再跑整套回归。前者还覆盖连接前/后与冷开、禁止未绑定 session；后者通过真实异步 DOM 操作确认不再弹出。没有延期的小项。本轮没有以第二次审阅代替修复测试。

测试中还修正了状态优先级；浏览器初轮的两个问题属于夹具：两模拟 App 共用同名锁域、以 JSON key 顺序比较布局。夹具改为分别模拟设备锁域并规范化比较后，真实接受/原件检查通过，未放宽产品校验。早期失败目录保留。
