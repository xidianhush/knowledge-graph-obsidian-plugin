# Knowledge Map 1.0 工程加固与同步引导实施计划

用户于本次对话确认计划并要求实施。日期：2026-11-24（Asia/Shanghai）。

目标：可靠维护、交付与插件内同步自引导；产品与工程理解并重。现有图谱可视化/交互保留。首批支持保持桌面及 iPad，Android 独立排期，iPhone 未验证；同步仍限定已验证 Windows/iPadOS/坚果云链路。

## 全局约束

- 不改插件 ID、布局 schema、同步协议、设备身份和恢复格式；不新增服务端/设置同步、不全量 TS 重写。
- 所有持久动作复用宿主及明确预览/确认；取消、页面引导、查找不变成授权。
- 不读 API Key 文件，不修改日常笔记；独立合成验证；私有证据不得公开。
- 不替用户宣称体验通过；外部试用、设备验收及正式发布保留门禁。

## 接口

新增内部纯函数 deriveSyncGuidance(state, context)，消费宿主状态、结果和页面查找状态，返回文案键、主要动作和详情。无I/O、无身份/协议变更；所有动作仍调既有宿主。

## 验证与放行

先相关回归，再默认检查。打包负例、状态推导、实际DOM流程/取消无写入、中英/窄宽/键盘/长消息、磁盘专项、原图谱与数据回归。最终Windows/iPad实际设置页、升级/备份/回退与用户体验另验。

至少两位未参与开发者分别尝试两条配置路径；缺少时记录证据缺口。性能固定合成样本/设备/构建/计时，前后比较，缺失指标披露。1.0候选冻结后dry run、版本映射/说明/三资产摘要一致，已发布资产不静默覆盖；最终发布按明确授权。未满足门槛不升1.0。

## 协作

每批交变更及原因、验证与限制、短原理说明；技术完成待用户验收。小批次可审阅差异；格式/行为/目录/构建改动分开，不提交混杂现场。

代码/文档实施状态勾选不表示产品或发布通过；设备、新用户及远端门禁仍见执行记录。
