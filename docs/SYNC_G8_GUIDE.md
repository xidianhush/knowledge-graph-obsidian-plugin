# G8 统一候选：短验收

2026-11-21。这是未正式发布的 0.0.15 版本号同步候选，目标发布版 0.0.16。以包名、插件名 **Knowledge Map G8 Candidate**、运行文件摘要区分版本。不要用版本号判断是否加载正确。

只使用包内新独立 PC/iPad 合成库；不覆盖日常库、原 G7/R2 库。关闭新库中的外部同步服务即可检查本次提示；无需坚果云传输或重做双向、离线、冲突、容量、正式版回退整轮。

## 安装检查点（尤其 iPad）

1. 解压后核对实际打开的库名 **Knowledge Map G8 PC / iPad**。源为本次候选包，目标为该库的 `.obsidian/plugins/knowledge-graph-smoke/`，不是压缩包、下载目录或其他同名库。隐藏目录须通过已有文件管理工具访问。
2. 替换既有独立测试库前，完全退出 Obsidian，并将整个插件目录另复制到库外。保留 App 私有状态、原库和全部恢复包。本次新库包包含合成初始 `data.json`；不能用它覆盖既有库数据。
3. 正常更新只复制 `main.js`、插件 `manifest.json`、`styles.css` 三文件，保留目标 `data.json`。实际目标只能用标准文件名加载；`main 2.js` 或带编号副本不代表已替换。完成复制确认后回到目标目录检查大小和 manifest 名称，必要时与 `verification.json` 的 SHA256 比对。源文件正确不等于目标已落盘。不要无备份批量删除；如文件管理器未完成覆盖，停在检查点保留全部副本。
4. 重开该独立库、启用插件并构图，设置名称应为 **Knowledge Map G8 Candidate**，应有“图谱布局同步”及本次新增的可见来源标签。若仍旧名/旧提示，不继续编辑，先核对实际目标三文件和打开的库。
5. 将来回退正式 0.0.15 时，必须先完整恢复备份，再明确选择兼容来源并导出兼容 `data.json`，库外复制完整包，退出后仅在获准测试库安装正式三件及所选兼容 data。恢复包内 manifest 不能代替插件 manifest。返回候选只换候选三件，保留旧版期间 data 并另存旧版新工作；旧版工作不会自动合入候选草稿。本次不要求重复这条已完成的 G7 PC/R2 流程。

## 五项短验

1. 构图后新建逻辑库、明确加入（导入本机布局）。关闭同步，拖动一个标题并结束调整。设置应明确“同步已关闭，本地工作保留”；重开后仍保留。启用后草稿需单独审阅，不自动发布。
2. 在同页导出完整恢复备份。兼容入口需要同步关闭、图谱就绪、无未保存及完整备份；离开重进会提示“本次设置页没有已核验备份凭据”，旧备份仍在。重新导出后入口恢复。
3. 来源选择有可见标签。先选“已保存但未发布的草稿”，再审阅；预览应写明草稿和路径。取消应无兼容文件。无需进行真实回退。
4. 可选独立库短检：先库外复制完整备份，再将本次库内备份目录改名。目录改名会按既有保护使图谱失效；若入口暂不可用，先完成构图更新，保持同一设置页，再审阅。应提示缺清单/路径、旧成功文字不再宣称当前有效，按钮要求重新导出。不要对原库/原备份做此操作。
5. iPad 仅补本次候选的一次完整退出重开、一次完整备份的等待感受与秒数（注明操作起止、实际操作/历史数量，和是否出现不可操作）。无需再填旧版切换流程。技术测量范围见结果文档，Node 数据不代替 iPad。

## 数据与已知边界

插件构图读取笔记，不改笔记；同步记录由用户选择的外部工具传输。共享 `Knowledge Map Sync` 包含相对路径、标题结构、坐标；设置、视角/UI留本机。同步私有日志和身份不只在 `data.json`，只备份此文件不足以完整恢复同步状态。恢复包/兼容包可能带配置及未知字段，保持私有，不进入公共 Release。摘要用于完整性校验，不是加密或来源认证。

库内备份请原位保留并**复制**到库外；备份目录不是共享操作目录。外部工具是否把恢复备份也加入传输取决于其范围配置，大量备份会增加文件工作量。插件不配置第三方限速/队列，不据此宣称坚果云限流已解决。

待用户决定：R7 坚果云一般限流 P1 未定因；R8 原 iPad 首轮异常 P1 未归因（R2 受控成功不能追认原因）；R9 约1200字符/390px合成长提示遮挡撤销 P3建议后移，未原生iPad真实错误复现。iPhone未测，Android计划0.0.17；OS可用空间和iPad内存上限未测。总体是否接受这些边界由用户判断，技术通过不代签产品验收。
