# 历史布局恢复候选验收（PC / iPadOS）

这是本地修复候选，**不代表正式 0.0.16 Release 已更新**。Windows 原生升级与独立浏览器测试已通过；2026-11-22用户已验收Science and Tech四目标在PC原库恢复、共享发布至iPad既有接收端及双端重开保持。其他历史组与iPad本机恢复入口未据此扩展为通过。

2026-11-22续验请使用 **PC-iPad-Layout-Recovery-20261122-2**（显示名 **Knowledge Map Layout Recovery Candidate 2**）。候选1在已有标题布局的会话中恢复其他分组会因缺失身份表报 `layout-identity`；候选2读取完整布局快照，保留未选分组及其身份表。原库该次失败不算恢复成功；安装候选2后仍先审阅恢复候选，发布另行确认。

## 正式版本与支持边界

- 本修复源码已整合到 `layout-recovery-integration` 分支（基线含正式 0.0.16 全部源码及此前已验收的加入修正）；正式版本号与发布范围待产品决定，本文不构成发布公告。正式发布后通过 Release 资产或社区插件渠道安装/升级，无需再手工替换候选文件；已加入会话保留现有接受记录与连接，升级不重新导入旧布局或重建连接。
- 单独一份当前 `data.json` **不能替代完整恢复包**：它不含完整接受账本与恢复清单。恢复前必须生成完整备份并读回验证，完整保留并复制到库外；未加入备份为 `initial-config.json` 加 manifest，已加入使用完整恢复导出格式。历史恢复来源可选完整备份内的原始 `data.json` 或 `join-backup.json`，不要选恢复 manifest、状态报告或设备身份文件。
- 支持边界：Windows 真实升级/恢复已验证；iPadOS 已验证共享布局接收端，**iPad 本机历史恢复入口未真机验收**；Android 不在本修复范围；因删除、改名、结构变化失配的旧布局不承诺全部原样恢复，以逐组预览的“原样/调整/无法恢复”为准。

## 安装前

先在独立库体验。实际库安装或恢复需按明确授权进行，不从计划行或此前候选安装授权推定。完整备份插件目录、整库和同步恢复数据；退出 Obsidian 后，仅替换 `main.js`、插件 `manifest.json`、`styles.css`。保留本机 `data.json`、App 私有身份/日志及完整备份。不要把测试库身份或数据复制进日常库。

## 升级保留检查

从未加入共享布局的设备：用 0.0.15 保存一个明显不同于默认的布局并重开，替换三运行文件后构图，检查对应位置。已加入设备不会重新导入旧布局或重建连接，继续使用现有接受记录/草稿。

## 逐组恢复

1. 构图，在插件设置打开 **恢复历史布局 / Restore historical layouts**，点 **审阅历史布局 / Review historical layouts**。默认读取本机保存的原始布局；如来源不对，可选私有备份内的原始 `data.json` 或 `join-backup.json` 再审阅。不要选择恢复 manifest、状态报告、设备身份文件。
2. 每组显示历史、当前和恢复候选。**默认不选择任何组**。先检查目标元素所属父分组；“原样”表示可保留原中心，“调整”会显示移动数量与最大移动量，“无法恢复”保持原始记录且不可选择。不同历史时期的截图只作参考。
3. 只勾选明确要恢复的分组，再点 **备份并恢复选中分组**。未选分组不覆盖；取消不写入。若图谱、来源或共享历史已变化，关闭并重新审阅，不强行重试旧预览。
4. 成功后保留新生成的完整恢复备份目录，并复制到库外。已加入设备只保存为本机草稿，不自动发布；先检查本机效果，再通过 **审阅待发布布局 / Review pending layout** 另行确认发布。
5. 让外部同步服务传完，再在另一端检查布局（必要时 **Check for layouts**）。按顺序操作，不同时改同一组。双端正常重开，确认位置、当前共享 ID 保留，并回报真实结果。

## 恢复失败或想回退

保留所有原文件、恢复目录和状态报告，不手工删除共享操作或私有日志。先停止新的布局操作，再分析具体错误。未加入配置备份为完整 `initial-config.json` 加最后写入并读回验证的 manifest；已加入备份使用现有完整恢复格式，二者都不是可替换的接受账本。

不要用 0.0.15 覆盖已经加入的新会话。需要运行文件回退时，完整备份并退出后恢复此前已兼容的三运行文件；需要数据恢复时先在独立副本审阅。此候选不承诺所有因删除、改名、结构变化而失配的旧布局都能原样恢复。

回报建议：所选分组、原样/调整状态、PC恢复效果、另一端是否接收、双端重开结果。真实笔记标题、布局数据、配置及截图保留为私有证据。
